# TaskFlow CI/CD Deployment Guide

## 🚀 Overview

This project includes a complete CI/CD pipeline using Jenkins, Terraform, Ansible, and Docker to automate the deployment of the TaskFlow application on AWS EC2.

## 📁 Project Structure

```
.
├── Jenkinsfile                 # Jenkins pipeline configuration
├── main.tf                     # Terraform infrastructure as code
├── deploy.yml                  # Ansible playbook for deployment
├── hosts.ini                   # Ansible inventory (auto-generated by Jenkins)
├── docker-compose.yaml         # Development Docker compose
├── docker-compose.prod.yml     # Production Docker compose
├── JENKINS_SETUP.md           # Detailed Jenkins setup guide
├── backend/
│   ├── Dockerfile             # Development backend Dockerfile
│   └── Dockerfile.prod        # Production backend Dockerfile
└── frontend/
    ├── Dockerfile             # Development frontend Dockerfile
    └── Dockerfile.prod        # Production frontend Dockerfile
```

## 🎯 Pipeline Workflow

The Jenkins pipeline automates the following stages:

1. **Checkout Code** - Pulls latest code from repository
2. **Terraform Init & Plan** - Initializes Terraform and creates execution plan
3. **Terraform Apply** - Provisions EC2 instance on AWS
4. **Build Docker Images** - Builds optimized production Docker images
5. **Push Docker Images** - Pushes images to Docker Hub/ECR
6. **Update Ansible Inventory** - Configures Ansible with EC2 IP
7. **Configure EC2 with Ansible** - Installs Docker, Nginx, and dependencies
8. **Deploy Containers** - Deploys application containers on EC2
9. **Verify Deployment** - Checks if services are running correctly

## 🛠️ Prerequisites

### 1. Jenkins Server Setup
- Jenkins installed and running
- Required plugins installed (see [JENKINS_SETUP.md](JENKINS_SETUP.md))
- Docker, Terraform, and Ansible installed on Jenkins server

### 2. AWS Account
- AWS account with appropriate IAM permissions
- AWS credentials configured in Jenkins

### 3. Docker Hub Account
- Docker Hub account for storing images
- Docker Hub credentials configured in Jenkins

### 4. SSH Key Pair
- SSH key pair generated for EC2 access
- Private key stored in Jenkins credentials
- Public key (`taskflow-key.pub`) in project root

## 🔐 Required Jenkins Credentials

Configure these credentials in Jenkins (Manage Jenkins → Manage Credentials):

| Credential ID | Type | Description |
|--------------|------|-------------|
| `dockerhub-credentials` | Username with password | Docker Hub login |
| `aws-credentials` | AWS Credentials | AWS Access Key and Secret |
| `ec2-ssh-key` | SSH Username with private key | EC2 instance access |

## 🚦 Quick Start

### Step 1: Configure Jenkins Credentials
```bash
# See JENKINS_SETUP.md for detailed instructions
```

### Step 2: Update Configuration Variables

Edit `Jenkinsfile` and update:
```groovy
DOCKER_HUB_REPO = 'yourusername/taskflow'  // Your Docker Hub username
```

Edit `main.tf` and update:
```hcl
bucket = "your-unique-bucket-name-2026"  // Must be globally unique
```

### Step 3: Create Jenkins Pipeline Job

1. Go to Jenkins Dashboard → New Item
2. Enter name: `TaskFlow-Deployment-Pipeline`
3. Select: **Pipeline**
4. Under Pipeline Definition, select: **Pipeline script from SCM**
5. SCM: **Git**
6. Repository URL: Your repository URL
7. Script Path: `Jenkinsfile`
8. Save

### Step 4: Run the Pipeline

1. Click "Build with Parameters"
2. Select ACTION: **deploy**
3. Click "Build"

The pipeline will:
- Provision EC2 instance
- Build and push Docker images
- Configure the server
- Deploy the application

### Step 5: Access Your Application

After successful deployment, the console output will show:
```
Frontend: http://<EC2-IP>:3000
Backend: http://<EC2-IP>:5000
SSH: ssh -i taskflow-key ubuntu@<EC2-IP>
```

## 📝 Configuration Files Explained

### Jenkinsfile
- Defines the complete CI/CD pipeline
- Includes stages for build, test, and deploy
- Supports both deploy and destroy actions

### main.tf (Terraform)
- Provisions EC2 t3.micro instance
- Creates S3 bucket for static hosting
- Configures security groups
- Sets up SSH key pair

### deploy.yml (Ansible)
- Installs Docker and dependencies
- Configures Nginx reverse proxy
- Deploys application containers
- Sets up monitoring and health checks

### Dockerfile.prod
- Production-optimized Docker images
- Multi-stage builds for smaller images
- Health checks included
- Non-root user for security

## 🔧 Manual Deployment (Alternative)

If you want to deploy without Jenkins:

### 1. Provision Infrastructure
```bash
# Initialize Terraform
terraform init

# Plan changes
terraform plan

# Apply configuration
terraform apply -auto-approve

# Get EC2 IP
export EC2_IP=$(terraform output -raw backend_public_ip)
echo $EC2_IP
```

### 2. Build and Push Docker Images
```bash
# Login to Docker Hub
docker login

# Build images
docker build -t yourusername/taskflow-backend:latest -f backend/Dockerfile.prod ./backend
docker build -t yourusername/taskflow-frontend:latest -f frontend/Dockerfile.prod ./frontend

# Push images
docker push yourusername/taskflow-backend:latest
docker push yourusername/taskflow-frontend:latest
```

### 3. Update Ansible Inventory
```bash
# Update hosts.ini with EC2 IP
cat > hosts.ini << EOF
[ec2_instances]
taskflow-server ansible_host=${EC2_IP} ansible_user=ubuntu ansible_ssh_private_key_file=./taskflow-key ansible_ssh_common_args='-o StrictHostKeyChecking=no'

[ec2_instances:vars]
docker_hub_repo=yourusername/taskflow
image_tag=latest
EOF
```

### 4. Deploy with Ansible
```bash
# Run Ansible playbook
ansible-playbook -i hosts.ini deploy.yml
```

### 5. Verify Deployment
```bash
# Check backend
curl http://${EC2_IP}:5000

# SSH into server
ssh -i taskflow-key ubuntu@${EC2_IP}

# Check running containers
docker ps
```

## 🗑️ Destroy Infrastructure

### Using Jenkins Pipeline
1. Click "Build with Parameters"
2. Select ACTION: **destroy**
3. Click "Build"

### Using Terraform Directly
```bash
terraform destroy -auto-approve
```

## 🐛 Troubleshooting

### Issue: Terraform state locked
```bash
terraform force-unlock <LOCK_ID>
```

### Issue: Docker permission denied on Jenkins
```bash
sudo usermod -aG docker jenkins
sudo systemctl restart jenkins
```

### Issue: Ansible can't connect to EC2
```bash
# Wait for EC2 to be ready (60 seconds after creation)
# Verify SSH key permissions
chmod 600 taskflow-key

# Test SSH connection
ssh -i taskflow-key ubuntu@<EC2-IP>
```

### Issue: Port already in use
```bash
# Stop existing containers
docker stop $(docker ps -aq)
docker rm $(docker ps -aq)
```

### Issue: Application not responding
```bash
# SSH into EC2
ssh -i taskflow-key ubuntu@<EC2-IP>

# Check container logs
docker logs taskflow-backend
docker logs taskflow-frontend
docker logs taskflow-mongo

# Check container status
docker ps -a

# Restart containers
docker restart taskflow-backend taskflow-frontend
```

## 🔒 Security Best Practices

1. **Never commit secrets** to version control
2. **Use strong JWT secrets** in production
3. **Rotate credentials** regularly
4. **Enable SSL/TLS** for production
5. **Use IAM roles** instead of access keys when possible
6. **Implement rate limiting** on API
7. **Enable CloudWatch** monitoring
8. **Set up automated backups** for MongoDB
